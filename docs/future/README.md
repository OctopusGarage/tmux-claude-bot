# Future Designs

Files in this directory are future-facing design or research notes. They are not
the source of truth for current runtime behavior.

Before using anything here for implementation, compare it with:

- `docs/intelligent-automation.md`
- `docs/automation-alignment.md`
- `docs/automation-capability-matrix.md`
- `docs/manual.md`
- live source and tests

If a future design contradicts maintained docs or code, treat the maintained docs
and source as authoritative. Migrate still-current material into maintained docs
before relying on it.
